# 🩺 XAI-Based Diabetes Prediction System

## 📌 Project Overview
This project predicts diabetes using **Machine Learning (Random Forest)** and **Deep Learning (Neural Networks)**.  
It also integrates **Explainable AI (XAI)** techniques to make the predictions transparent and interpretable.

## ⚙️ Technologies Used
- Python
- Scikit-learn
- TensorFlow / Keras
- SHAP
- LIME
- Partial Dependence Plots (PDP)
- ICE Plots
- Feature Importance
- Integrated Gradients

## 🚀 Features
- Train a Random Forest model for diabetes prediction
- Visualize **SHAP values** for feature importance
- Generate **LIME explanations** for individual predictions
- Plot **PDP & ICE curves** to understand feature effects
- Show **Random Forest feature importance**
- Train a simple **Neural Network** and explain it using **Integrated Gradients**
